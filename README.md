# Chess Puzzles

A native iOS / Android chess puzzle app built with Expo + React Native
+ TypeScript. Solve mate-in-N and tactical puzzles against a timer,
scored on speed and difficulty.

The entire app lives under [`mobile/`](./mobile). Start there:

```bash
cd mobile
npm install
npm run start
```

See [`mobile/README.md`](./mobile/README.md) for the full setup, the
Lichess puzzle importer (to swell the bank from 15 hand-curated
puzzles to thousands), and iOS deploy instructions via EAS Build.
